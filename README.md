# Conectate-Tech 💻

**Trabajo Práctico 2 - Aplicaciones Híbridas**

¡Bienvenidos a Conectate-Tech! Una plataforma e-commerce simulada de hardware, desarrollada íntegramente con React.js. Este proyecto fue creado para gestionar un catálogo de componentes de PC, diferenciando la experiencia entre clientes comunes y administradores.

## 🛠️ Tecnologías y Herramientas
* **Frontend:** React.js (Componentes funcionales y Hooks).
* **Enrutamiento:** React Router DOM.
* **Estado:** Context API / Hooks.
* **Datos:** Simulación de base de datos local (JSON).

## 🚀 Funcionalidades Principales
* **Catálogo de Hardware:** Listado completo de productos (CPUs, GPUs, Periféricos, etc.) separados por categorías.
* **Sistema de Usuarios y Roles:** Simulación de Login/Logout con diferenciación entre rol `Administrador` y rol `Común`.
* **Renderizado Condicional:** La interfaz se adapta según el rol logueado.
* **Gestión de Inventario (CRUD):** El administrador cuenta con una interfaz gráfica exclusiva para:
  * Listar y ver detalles de productos.
  * Agregar nuevo hardware.
  * Editar especificaciones y precios.
  * Eliminar productos del catálogo.
* **Validaciones:** Formularios protegidos con validaciones básicas para evitar datos incorrectos.
